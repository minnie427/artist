If the folders were already created with `showreel/`, use that folder as `selected/`; it does not need to be renamed now.

## What goes where

- Put the strongest project image inside that project’s `hero/` folder.
- Put every other image and video directly inside the project folder. Subfolders for photography, generated visuals or documentation are optional, not required.
- Put the images that should appear in the opening `Selected Images` strip inside `artist/selected/` (or the existing `artist/showreel/`).
- Put portraits and photographs of Minnie working inside `artist/profile/`.
- Put the updated artist CV and Honours exegesis inside `documents/`.
- Put anything uncertain inside `unsorted/`; it can be classified during import.

## Images and videos

JPG, JPEG, PNG, WEBP, HEIC, TIFF, MP4, MOV and WEBM can remain in their original formats while collecting. Keep the largest original rather than a screenshot when possible.

During site import:

- `hero/` supplies the first project image.
- The remaining images join the project gallery and Visual Index.
- Videos join the same chronological Visual Index as images. They appear as muted moving tiles and open with playback controls in the large viewer.
- MOV files are converted to web-compatible MP4 or WEBM copies before they are added to the live site; the MOV originals remain untouched.
- Web-size images, video posters and compressed copies are generated later; the originals remain untouched.

## Minimum priority

Collect one hero image for Funeral, Shared Resonance, Meta Kibun and Origin first. After that, add audience interaction, full installation views, tactile details and clearly different generated visual states. The number of files does not need to be equal across projects.
